# Ruangan kelas referensi video dan denah

Prefab lengkap: Prefabs/Ruangan Kelas Referensi.prefab. Kursi terpisah: Prefabs/Kursi Kayu Berlengan.prefab. Pratinjau: Scenes/Pratinjau Ruangan Kelas.unity. Model portabel: Ruangan Kelas Referensi.obj + .mtl + folder Textures.

Dimensi rancangan16.8x10.8x3.6m; belum pengukuran lapangan. Lebar dua kali versi sebelumnya. Denah:100 kursi,42 kiri,42 kanan,16 di belakang. Jarak pusat kursi pada blok0.90m; jarak baris0.95m; deret belakang0.85m. Semua menghadap papan tulis di tengah dinding depan. Dua pintu di dinding kanan. Skala kursi tetap, bukan diregangkan. Proyektor gantung tetap tersedia. Engsel pintu dapat diputar. Semua bukaan jendela/pintu memakai geometri terpisah. Kaca dapat dinonaktifkan bila perlu. Tekstur512 dengan mipmap dan kompresi ETC2 Android. Collider sederhana untuk kursi, mesh collider pada bangunan. Aset terpisah; belum mengganti ruang GK2.
