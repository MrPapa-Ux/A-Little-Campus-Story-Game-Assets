# Checkpoint

**Editor** — alat untuk bekerja di Unity Editor; bukan untuk dipasang pada GameObject.

[Kembali ke panduan utama](<../../MULAI DI SINI.md>)

Alat revisi/checkpoint dapat membentuk ulang scene atau UI sesuai versi saat dibuat. Baca isi `Apply` sebelum menjalankan alat lama pada scene yang sudah diedit. Checkpoint bukan tombol undo otomatis.
