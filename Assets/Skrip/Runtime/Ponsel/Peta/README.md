# Ponsel / Peta

**Runtime** — berjalan bersama game.

[Kembali ke panduan utama](<../../../MULAI DI SINI.md>)

## GeserPetaHP.cs

[Buka skrip](<GeserPetaHP.cs>)

Menerjemahkan drag dan scroll menjadi pergeseran atau zoom peta.

**Tipe di dalam berkas:** `GeserPetaHP`.

**Pintu fungsi publik:** `OnBeginDrag()`, `OnDrag()`, `OnScroll()`.

## LingkaranPeta.cs

[Buka skrip](<LingkaranPeta.cs>)

Menggambar penanda lokasi peta dengan garis coretan.

**Tipe di dalam berkas:** `LingkaranPeta`.

## PetaKampusHP.cs

[Buka skrip](<PetaKampusHP.cs>)

Mengatur titik peta, pilihan kiri/kanan, fokus lokasi, zoom, dan batas geser.

**Tipe di dalam berkas:** `TitikPetaKampus`, `PetaKampusHP`.

**Pintu fungsi publik:** `PilihKanan()`, `PilihKiri()`, `SentuhLokasi()`, `Interaksi()`, `LihatSemua()`, `Perbesar()`, `Perkecil()`, `Tutup()`, `Geser()`, `AturZoomLangsung()`.
